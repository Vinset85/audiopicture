# Sheet 01 — Ethernet / PoE / W5500 Rev.A

Status: **implementable schematic specification**. Exact PoE MagJack and bridge MPNs remain VALIDATE until pinout, isolation and mechanical footprint are jointly frozen.

## 1. Ethernet controller
U2: **WIZnet W5500**, 48-LQFP, 3.3 V.

Functions:
- 10BASE-T / 100BASE-TX PHY
- hardware TCP/IP engine
- SPI host interface
- reset and interrupt to ESP32-S3.

Supply: +3V3_SYS.

## 2. W5500 reference components
Rev.A follows the official WIZnet reference schematic rather than deriving a custom PHY network.

### Reference resistor
EXRES1 -> **4.12 kOhm, 1%** -> GND.

### Clock
Y201: **25 MHz crystal**.
Initial reference network:
- 1 Mohm feedback resistor across XI/XO where required by WIZnet reference;
- 18 pF load capacitors baseline, final values calculated from selected crystal CL and PCB stray capacitance.

Exact crystal MPN remains VALIDATE.

### Reset / interrupt
RSTn:
- 10 kOhm pull-up to +3V3_SYS baseline;
- ESP32 signal ETH_RST;
- boot hardware must hold/provide valid reset timing independent of firmware race conditions.

INTn:
- 10 kOhm pull-up to +3V3_SYS baseline;
- ESP32 signal ETH_INT.

### Mode pins
PMODE[2:0] are strapped for variable-length data mode / intended SPI operation according to the current W5500 reference design. Exact strap truth table shall be checked at schematic capture and documented adjacent to the resistors.

## 3. Host SPI
Signals:
- SPI_SCLK
- SPI_MOSI
- SPI_MISO
- ETH_CS
- ETH_RST
- ETH_INT

ESP32 baseline:
GPIO10 ETH_CS
GPIO11 MOSI
GPIO12 SCLK
GPIO13 MISO
GPIO8 ETH_RST
GPIO9 ETH_INT

Provide optional source-side 22–33 ohm series resistor footprints on SCLK/MOSI/CS if SI tuning is required. Populate only after measurement unless reference layout demands otherwise.

## 4. MDI
W5500 differential PHY nets:
- TXP/TXN
- RXP/RXN.

Follow WIZnet reference schematic and layout exactly for termination and transformer interface.

Reference/module precedent uses **33 ohm series resistors** on TXP/TXN/RXP/RXN. These are the Rev.A baseline values and must be verified against the exact current W5500 reference schematic at capture.

Route as 100-ohm differential pairs through magnetics to RJ45.

No stubs.
No test pads on high-speed MDI pairs.
Keep pair members length matched and symmetric.
Keep PHY-to-magnetics distance short.

## 5. MagJack strategy
AudioPicture needs BOTH:
1. W5500 Ethernet magnetics;
2. IEEE 802.3af/at power extraction for Ag5324 including alternative pairs.

Therefore J1 must expose the required PoE center taps/pairs to the PD rectifier network.

Preferred selection criteria:
- integrated 10/100 magnetics;
- PoE+ / 802.3at suitable;
- access to data-pair center taps and spare pairs as required;
- shielded RJ45;
- integrated Link/Activity LEDs optional;
- mechanical height compatible with rear bay;
- isolation rating consistent with Ethernet/PoE requirements.

Avoid a MagJack whose internal center-tap topology prevents the W5500 reference termination from being implemented correctly.

Exact J1 MPN: VALIDATE_POE_PINOUT_MECHANICAL.

## 6. PoE front end
Silvertel U3: **Ag5324**.

PoE cable-side feeds two bridge rectifiers so the PD accepts both polarity and powering arrangements:
- BR1 data-pair feed
- BR2 spare-pair feed
-> Ag5324 VIN+ / VIN-.

Ag5324:
- IEEE 802.3af/at PD module
- fixed Class 4
- input 36–57 V
- nominal 24 V isolated output
- output adjustable approximately 22.8–25.2 V
- up to 30 W peak / 24 W continuous under current datasheet conditions.

Secondary:
Ag5324 +VDC -> +24V_POE
Ag5324 -VDC -> GND_SYS

Do NOT connect PoE cable-side primary return to GND_SYS.

## 7. PoE bridges
BR201/BR202 exact MPN: VALIDATE.

Requirements:
- reverse voltage/current appropriate to PoE input;
- low forward loss;
- thermal performance for Class-4 operation;
- package compatible with isolation/creepage layout;
- selected from Silvertel recommended/reference components where possible.

Do not substitute arbitrary low-voltage bridge rectifiers.

## 8. Ag5324 output network
Populate output electrolytic and adjustment/filter components per the current Silvertel Ag5300/Ag5324 datasheet.

+24V_POE feeds the isolated-secondary ideal-diode/ORing stage defined in Sheet 02.

The PoE module output capacitance must be included in total startup/inrush analysis; do not independently increase it without checking PSE startup behavior and module limits.

## 9. PoE presence
POE_PRESENT is sensed only on the isolated secondary side from +24V_POE.

It must:
- tolerate full 25.2 V adjusted maximum plus transient margin;
- not phantom-power ESP32 when +3V3_SYS is absent;
- present a valid logic state before firmware source selection.

Exact comparator/divider implementation belongs to Sheet 02/03.

## 10. Ethernet LEDs
Preferred:
- LINK
- ACTIVITY

LEDs may be physically hidden/rear-facing; they are primarily service indicators.

Series resistors shall be calculated for the selected LED and W5500 LED output configuration. Do not allow front internal LED leakage to reach OPT3004.

## 11. Shield / chassis strategy
RJ45 shield is not blindly shorted to digital GND.

Baseline:
- connector shield / chassis net = CHASSIS_ETH;
- optional high-voltage capacitor coupling to GND_SYS derived from Ethernet reference practice;
- final connection depends on enclosure EMC strategy.

Reference precedent uses a ~1 nF / 2 kV-class capacitor between chassis and circuit ground. Final value is VALIDATE_EMC_SAFETY.

## 12. Placement
Connector edge -> magnetics -> W5500 should be compact.

PoE high-voltage/cable-side circuitry remains physically on the connector side of the isolation boundary.

Keep:
- Class-D outputs,
- TPSM63603 switch node,
- ESP32 antenna
away from MDI/magnetics.

No copper crossing the Ag5324 isolation boundary except components/signals explicitly allowed by its certified topology.

## MagJack production selection update
Pulse J0011D21BNL is explicitly rejected for the AudioPicture PoE BOM because Pulse classifies it as NON-POE. It remains relevant only as a W5500 non-PoE electrical reference.

The production Ethernet front end must use a PoE-rated magnetics topology with accessible center taps/spare-pair power extraction compatible with the two-bridge Silvertel reference input. If no integrated MagJack satisfies both W5500 termination and PoE extraction cleanly, use discrete Ethernet magnetics plus a shielded RJ45 rather than compromising either interface.

WIZnet's connected-center-tap caution must be applied to the final magnetics schematic.
