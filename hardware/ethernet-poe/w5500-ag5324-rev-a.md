# Sheet 01 — Ethernet / PoE / W5500 Rev.A

Status: **implementable schematic specification**. Exact PoE MagJack and bridge MPNs remain VALIDATE until pinout, isolation and mechanical footprint are jointly frozen.

## 1. Ethernet controller
U2: **WIZnet W5500**, 48-LQFP, 3.3 V.

Functions:
- 10BASE-T / 100BASE-TX PHY
- hardware TCP/IP engine
- SPI host interface
- reset and interrupt to ESP32-S3.

Supply: +3V3_SYS.

## 2. W5500 reference components
Rev.A follows the official WIZnet reference schematic rather than deriving a custom PHY network.

### Reference resistor
EXRES1 -> **4.12 kOhm, 1%** -> GND.

### Clock
Y201: **25 MHz crystal**.
Initial reference network:
- 1 Mohm feedback resistor across XI/XO where required by WIZnet reference;
- 18 pF load capacitors baseline, final values calculated from selected crystal CL and PCB stray capacitance.

Exact crystal MPN remains VALIDATE.

### Reset / interrupt
RSTn:
- 10 kOhm pull-up to +3V3_SYS baseline;
- ESP32 signal ETH_RST;
- boot hardware must hold/provide valid reset timing independent of firmware race conditions.

INTn:
- 10 kOhm pull-up to +3V3_SYS baseline;
- ESP32 signal ETH_INT.

### Mode pins
PMODE[2:0] are strapped for variable-length data mode / intended SPI operation according to the current W5500 reference design. Exact strap truth table shall be checked at schematic capture and documented adjacent to the resistors.

## 3. Host SPI
Signals:
- SPI_SCLK
- SPI_MOSI
- SPI_MISO
- ETH_CS
- ETH_RST
- ETH_INT

ESP32 baseline:
GPIO10 ETH_CS

Provide optional source-side 22–33 ohm series resistor footprints on SCLK/MOSI/CS if SI tuning is required. Populate only after measurement unless reference layout demands otherwise.

## 4. MDI
W5500 differential PHY nets:
- TXP/TXN
- RXP/RXN.

Follow WIZnet reference schematic and layout exactly for termination and transformer interface.

Reference/module precedent uses **33 ohm series resistors** on TXP/TXN/RXP/RXN. These are the Rev.A baseline values and must be verified against the exact current W5500 reference schematic at capture.

Route as 100-ohm differential pairs through magnetics to RJ45.

No stubs.
No test pads on high-speed MDI pairs.
Keep pair members length matched and symmetric.
Keep PHY-to-magnetics distance short.

## 5. MagJack strategy
AudioPicture needs BOTH:
1. W5500 Ethernet magnetics;
2. IEEE 802.3af/at power extraction for Ag5324 including alternative pairs.

Therefore J1 must expose the required PoE center taps/pairs to the PD rectifier network.

Preferred selection criteria:
- integrated 10/100 magnetics;
- PoE+ / 802.3at suitable;
- access to data-pair center taps and spare pairs as required;
- shielded RJ45;
- integrated Link/Activity LEDs optional;
- mechanical height compatible with rear bay;
- isolation rating consistent with Ethernet/PoE requirements.

Avoid a MagJack whose internal center-tap topology prevents the W5500 reference termination from being implemented correctly.

Exact J1 MPN: VALIDATE_POE_PINOUT_MECHANICAL.

## 6. PoE front end
Silvertel U3: **Ag5324**.

PoE cable-side feeds two bridge rectifiers so the PD accepts both polarity and powering arrangements:
- BR1 data-pair feed
- BR2 spare-pair feed
-> Ag5324 VIN+ / VIN-.

Ag5324:
- IEEE 802.3af/at PD module
- fixed Class 4
- input 36–57 V
- nominal 24 V isolated output
- output adjustable approximately 22.8–25.2 V
- up to 30 W peak / 24 W continuous under current datasheet conditions.

Secondary:
Ag5324 +VDC -> +24V_POE
Ag5324 -VDC -> GND_SYS

Do NOT connect PoE cable-side primary return to GND_SYS.

## 7. PoE bridges
BR201/BR202 exact MPN: VALIDATE.

Requirements:
- reverse voltage/current appropriate to PoE input;
- low forward loss;
- thermal performance for Class-4 operation;
- package compatible with isolation/creepage layout;
- selected from Silvertel recommended/reference components where possible.

Do not substitute arbitrary low-voltage bridge rectifiers.

## 8. Ag5324 output network
Populate output electrolytic and adjustment/filter components per the current Silvertel Ag5300/Ag5324 datasheet.

+24V_POE feeds the isolated-secondary ideal-diode/ORing stage defined in Sheet 02.

The PoE module output capacitance must be included in total startup/inrush analysis; do not independently increase it without checking PSE startup behavior and module limits.

## 9. PoE presence
POE_PRESENT is sensed only on the isolated secondary side from +24V_POE.

It must:
- tolerate full 25.2 V adjusted maximum plus transient margin;
- not phantom-power ESP32 when +3V3_SYS is absent;
- present a valid logic state before firmware source selection.

Exact comparator/divider implementation belongs to Sheet 02/03.

## 10. Ethernet LEDs
Preferred:
- LINK
- ACTIVITY

LEDs may be physically hidden/rear-facing; they are primarily service indicators.

Series resistors shall be calculated for the selected LED and W5500 LED output configuration. Do not allow front internal LED leakage to reach OPT3004.

## 11. Shield / chassis strategy
RJ45 shield is not blindly shorted to digital GND.

Baseline:
- connector shield / chassis net = CHASSIS_ETH;
- optional high-voltage capacitor coupling to GND_SYS derived from Ethernet reference practice;
- final connection depends on enclosure EMC strategy.

Reference precedent uses a ~1 nF / 2 kV-class capacitor between chassis and circuit ground. Final value is VALIDATE_EMC_SAFETY.

## 12. Placement
Connector edge -> magnetics -> W5500 should be compact.

PoE high-voltage/cable-side circuitry remains physically on the connector side of the isolation boundary.

Keep:
- Class-D outputs,
- TPSM63603 switch node,
- ESP32 antenna
away from MDI/magnetics.

No copper crossing the Ag5324 isolation boundary except components/signals explicitly allowed by its certified topology.

## MagJack production selection update
Pulse J0011D21BNL is explicitly rejected for the AudioPicture PoE BOM because Pulse classifies it as NON-POE. It remains relevant only as a W5500 non-PoE electrical reference.

The production Ethernet front end must use a PoE-rated magnetics topology with accessible center taps/spare-pair power extraction compatible with the two-bridge Silvertel reference input. If no integrated MagJack satisfies both W5500 termination and PoE extraction cleanly, use discrete Ethernet magnetics plus a shielded RJ45 rather than compromising either interface.

WIZnet's connected-center-tap caution must be applied to the final magnetics schematic.


## Rev.A production decision — discrete magnetics
The MAIN Rev.A Ethernet/PoE front end shall use **discrete 10/100 Ethernet magnetics plus a shielded RJ45**, rather than freezing an integrated MagJack.

Rationale:
- W5500 has an explicit manufacturer reference topology for external magnetics.
- Cable-side data-pair center taps remain fully visible for PoE Alternative A extraction.
- RJ45 spare pairs 4/5 and 7/8 remain fully visible for Alternative B extraction.
- The two Silvertel bridge rectifiers can therefore be implemented and audited without hidden MagJack internal connections.
- PHY-side W5500 center-tap/termination network can follow the WIZnet external-transformer reference directly.
- CHASSIS_ETH remains explicit and independent of GND_SYS.

### Magnetics candidate
Pulse **H1102NL** is the initial external-transformer candidate because WIZnet lists it in the W5500 external-transformer reference recommendations.

Status: CANDIDATE_REFERENCE_PART.
Before Gerber release verify current manufacturer datasheet, PoE DC-current suitability on the cable-side windings/center taps, insulation, footprint and availability. If its PoE current rating is not sufficient for 802.3at Class 4, select a PoE+ rated 10/100 1:1 transformer with equivalent W5500 electrical characteristics.

### RJ45
Use a shielded 8P8C right-angle RJ45 with all eight contacts independently exposed and no integrated magnetics/bridges.
Required:
- pins 1..8 accessible;
- shield tabs -> CHASSIS_ETH;
- <=40 mm enclosure depth;
- robust through-hole mechanical tabs preferred;
- LEDs optional.

Exact MPN remains VALIDATE_MECHANICAL_AVAILABILITY.

### Cable-side PoE extraction
Alternative A:
- transformer cable-side center taps -> BR201 input.

Alternative B:
- RJ45 pairs 4/5 and 7/8 -> BR202 input.

BR201/BR202 outputs feed only the Ag53024/Ag5324 PoE primary input. The isolated 24 V secondary becomes +24V_POE / GND_SYS.

This topology is now preferred over an integrated PoE MagJack for Rev.A.


## Rev.A bridge technology update
BR201/BR202 baseline is now **discrete Schottky bridge rectification** (8 diode elements total), replacing DF01S as the preferred production implementation.

Silvertel's current PoE power guidance shows approximately 0.9 V/element for DF01S-class silicon rectification versus <0.4 V/element for an SS36 Schottky implementation. Active FDMQ8205A rectification has still lower loss but is retained only as an optional thermal optimization.

Exact Schottky MPN remains to be frozen after reverse-voltage/transient and thermal review.

## Transformer current gate
Bourns SM13126PEL is explicitly rated up to 350 mA PoE current. It remains the preferred dimensional/electrical candidate but is not yet production-frozen for Type-2/Class-4. Verify the rating against the maximum current-per-pair required by the Ag53024 operating envelope before Gerber release.


## Rev.A transformer freeze
T_ETH production baseline is now **Wurth 7490220121**.

Reason:
- W5500 specifies 1:1, 350 uH on both TX and RX;
- 7490220121 provides 350 uH minimum;
- 600 mA per centre tap PoE capability;
- 1500 Vrms isolation;
- official KiCad/STEP/S-parameter assets.

The part is a four-channel 10/100/1000 transformer and is oversized for the two-channel W5500. Rev.A accepts this size penalty to remove electrical uncertainty. Only the required 100BASE-TX channels are used; treatment of unused windings follows the manufacturer guidance.

Compact 110/120/150 uH PoE+ parts are not Rev.A substitutes because they do not meet the W5500 datasheet's stated 350 uH transformer characteristic.


## MAIN Rev.A Ethernet/PoE physical floorplan baseline

### Placement order
From enclosure/cable edge toward system electronics:
1. shielded plain 8P8C RJ45;
2. cable-side PoE extraction nodes;
3. T_ETH Wurth 7490220121;
4. W5500 on the SELV/system side of T_ETH;

6. Ag53024 across the isolation boundary;
7. +24V_POE secondary filtering/sense;
8. LM74700 PoE ORing branch toward +24V_RAW.

### Isolation zoning
Create explicit PCB regions:
- ETH_CABLE_PRIMARY: RJ45 cable contacts, cable-side transformer windings/center taps, BR201/BR202 and Ag53024 primary pins.
- SELV_SYSTEM: W5500 PHY side, Ag53024 isolated output, +24V_POE and all system rails/GND_SYS.
- CHASSIS: RJ45 shield and optional EMC coupling network.

No GND_SYS copper pour shall enter ETH_CABLE_PRIMARY.
No ordinary signal/power trace crosses the isolation corridor except through intentionally isolated/rated components.

### Isolation corridor
Reserve a 6.0 mm nominal no-copper/no-via corridor between PoE primary and SELV secondary regions during Rev.A placement.

This is a conservative layout baseline, not a final regulatory compliance declaration. Final creepage/clearance must be checked against IEC 62368-1, PCB CTI/material group, pollution degree, working/transient voltage, Silvertel guidance and enclosure construction.

### RJ45 / transformer / MDI
- RJ45 directly at board/enclosure edge.
- T_ETH immediately behind RJ45.
- Cable-side MDI pairs short, symmetric and without stubs.
- W5500-to-transformer MDI routed as 100 ohm differential.
- No MDI pogo/test pads.

### Secondary

The MAIN Rev.A Ethernet connector shall be a **plain shielded 8P8C modular jack without integrated magnetics**.

Mandatory:
- all eight contact pins individually exposed to PCB;
- no integrated Ethernet transformer;
- no integrated bridge rectifier;
- no internal common-mode network that alters PoE pair access;
- shield tabs separately exposed as CHASSIS_ETH;
- right-angle cable entry;
- through-hole mechanical retention / shield stakes preferred;

Preferred:

## Rev.A rectifier freeze
BR201/BR202 are implemented from eight **STPST3H100AF** discrete trench Schottky diodes (four per bridge).

The 100 V VRRM class is intentional. The Silvertel Ag5300-family reference data specifies 57 V maximum recommended input and 80 V/1 ms absolute input surge. 60 V Schottky parts therefore do not provide sufficient engineering margin for Rev.A.

Use ST SOD128Flat recommended land pattern and thermal copper guidance. Keep each bridge compact; minimize the high-current loop from PoE extraction to bridge to Ag53024 VIN.

### PoE continuous application budget correction
Current Silvertel datasheet section 3.1 states the application should be designed for **22.5 W maximum continuous output** in a fully compliant IEEE802.3at system.

Therefore:
- POE_SYSTEM_CONTINUOUS_BUDGET = 22.5 W;
- module nominal capability = 24 W continuous under suitable conditions;
- 30 W = short transient peak only;
- TAS5825M PoE limiter must leave headroom for W5500, ESP32-S3, voice, radar, sensors and rail-conversion losses.

This supersedes earlier text that treated 24 W as the usable continuous system budget.
