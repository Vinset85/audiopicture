# Firmware

Production firmware target: ESP32-S3 using ESP-IDF with product-specific AudioPicture components.

Subsystems:
- Device Manager
- Network Manager (Ethernet primary, Wi-Fi fallback)
- Power Manager
- Audio Engine
- XVF3800 Driver
- TAS5825M DSP Manager
- Radar Engine
- Environmental Sensors
- Acoustic Calibration Engine
- Multiroom Sync Engine
- Home Assistant discovery/API
- OTA / rollback / recovery
- Factory provisioning and diagnostics
